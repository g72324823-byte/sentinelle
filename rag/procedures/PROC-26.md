# PROC-26 — Hameçonnage par SMS

## Objet

Des fraudeurs envoient de faux SMS au nom de Dalla Pay pour obtenir le code secret des clients.

## Déroulement

1. Rappeler au client que Dalla Pay ne demande jamais son code secret.
2. Relever le numéro expéditeur et le texte du SMS, puis le transmettre à l'équipe fraude.
3. Si le client a donné son code, bloquer le compte et lui faire changer le code chez un agent.

## Règles et seuils

- Les SMS officiels de Dalla Pay viennent uniquement de l'expéditeur DALLAPAY.
